# Visão Geral — Conexão Solidária

## Contexto

Organizações do terceiro setor utilizam a comunicação digital para apresentar suas iniciativas, divulgar projetos, mobilizar voluntários e estabelecer contato com diferentes públicos.

Nesse contexto, uma aplicação web precisa combinar organização visual, responsividade, acessibilidade e interatividade para proporcionar uma experiência de navegação clara em diferentes dispositivos.

O **Conexão Solidária** surgiu como projeto acadêmico durante a disciplina de **Desenvolvimento Front-end para Web**, da graduação em Análise e Desenvolvimento de Sistemas.

## Proposta

O projeto propõe uma aplicação web voltada ao contexto de organizações do terceiro setor, utilizando seu desenvolvimento como ambiente prático para aplicação progressiva de fundamentos de front-end.

Sua evolução acadêmica ocorreu em duas etapas principais:

1. construção de uma interface responsiva e estruturada;
2. evolução conceitual da interface para uma aplicação dinâmica utilizando JavaScript.

## Objetivos

O projeto busca aplicar e consolidar conhecimentos relacionados a:

- estruturação semântica de interfaces;
- estilização e organização visual;
- responsividade;
- componentes reutilizáveis;
- acessibilidade;
- manipulação do DOM;
- controle de eventos;
- navegação em Single Page Application;
- validação de formulários;
- persistência de informações no navegador;
- organização modular de código JavaScript.

## Evolução acadêmica

### Experiência Prática II

A primeira etapa concentrou-se na estrutura visual da aplicação, explorando HTML, CSS, Design System, CSS Grid, Flexbox, Media Queries, componentes responsivos e estados de interação.

### Experiência Prática III

A segunda etapa avançou para os fundamentos de programação para interfaces web, abordando JavaScript, manipulação do DOM, SPA, History API, templates dinâmicos, eventos, validação, localStorage, JSON, modularização e depuração.

## Estado atual

O Conexão Solidária encontra-se atualmente documentado como **projeto acadêmico conceitual**.

As estruturas e soluções descritas neste repositório representam os conceitos trabalhados durante as experiências práticas. Uma implementação integral e executável em código-fonte poderá ser desenvolvida posteriormente como evolução do projeto.

## Próximos passos

A evolução planejada consiste em transformar progressivamente a especificação acadêmica em uma aplicação funcional utilizando HTML, CSS e Vanilla JavaScript, permitindo aplicar em código os conhecimentos desenvolvidos durante a graduação.

O planejamento dessa evolução está registrado no arquivo [`ROADMAP.md`](../ROADMAP.md).
