# Conexão Solidária

### Aplicação Web Responsiva e Interativa para Organizações do Terceiro Setor

> Projeto acadêmico desenvolvido progressivamente durante a disciplina de Desenvolvimento Front-end para Web, aplicando fundamentos de HTML, CSS e JavaScript na construção de uma aplicação web responsiva e dinâmica.

**Status:** Projeto acadêmico concluído e em documentação

---

## Sobre o projeto

O **Conexão Solidária** é uma aplicação web desenvolvida com foco em organizações do terceiro setor.

O projeto foi construído progressivamente durante experiências práticas da graduação em **Análise e Desenvolvimento de Sistemas**, permitindo aplicar conceitos de desenvolvimento front-end desde a estruturação visual da interface até a implementação de comportamentos dinâmicos com JavaScript.

A evolução do projeto ocorreu em duas etapas principais:

### Versão 1 — Interface responsiva

A primeira etapa concentrou-se na construção e organização da interface, trabalhando conceitos como:

- HTML semântico
- CSS
- Design System
- CSS Grid
- Flexbox
- Responsividade
- Media Queries
- Componentes visuais
- Estados interativos
- Princípios de acessibilidade

### Versão 2 — Conexão Solidária Interativa

Na segunda etapa, a interface evoluiu para uma aplicação dinâmica utilizando **Vanilla JavaScript**.

Foram trabalhados conceitos como:

- Manipulação do DOM
- Single Page Application (SPA)
- History API
- Controle de eventos
- Templates dinâmicos
- Validação de formulários
- Persistência de dados com localStorage
- JSON
- Modularização com import/export
- Depuração com DevTools

## Arquitetura JavaScript

Durante a evolução da aplicação, as responsabilidades do código foram separadas em módulos específicos, incluindo:

- `router.js` — gerenciamento da navegação da SPA
- `templates.js` — geração de conteúdos dinâmicos
- `forms.js` — tratamento e validação de formulários
- `storage.js` — persistência e recuperação de dados

Essa organização busca reduzir o acoplamento e tornar o código mais legível, reutilizável e fácil de manter.

## Aprendizados

O desenvolvimento do projeto permitiu compreender, na prática, como uma interface inicialmente estática pode evoluir para uma aplicação web interativa.

Além da implementação das funcionalidades, o projeto contribuiu para o aprendizado sobre organização de código, separação de responsabilidades, manipulação do DOM, gerenciamento de eventos e persistência de informações no navegador.

## Contexto acadêmico

O projeto foi desenvolvido durante a disciplina **Desenvolvimento Front-end para Web**, da graduação em **Análise e Desenvolvimento de Sistemas**.

A construção ocorreu principalmente durante as **Experiências Práticas II e III**, permitindo acompanhar a evolução da aplicação desde sua camada visual e responsiva até a implementação de comportamentos dinâmicos utilizando JavaScript.
