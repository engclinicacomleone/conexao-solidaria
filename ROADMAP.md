# Roadmap — Conexão Solidária

Este roadmap registra a evolução do **Conexão Solidária**, desde sua concepção nas experiências práticas da graduação até uma possível implementação funcional futura.

O projeto foi inicialmente desenvolvido em caráter acadêmico, por meio da definição e descrição de estruturas, componentes e comportamentos de uma aplicação web.

## Fase 1 — Estrutura e interface responsiva

**Status: Concluída academicamente**

Conceitos trabalhados durante a Experiência Prática II:

- [x] Estruturação da interface
- [x] HTML semântico
- [x] Design System
- [x] CSS Grid
- [x] Flexbox
- [x] Responsividade
- [x] Media Queries
- [x] Componentes visuais
- [x] Estados interativos
- [x] Princípios de acessibilidade

## Fase 2 — Interatividade com JavaScript

**Status: Concluída academicamente**

Conceitos trabalhados durante a Experiência Prática III:

- [x] Manipulação do DOM
- [x] Navegação em Single Page Application
- [x] History API
- [x] Controle de eventos
- [x] Templates dinâmicos
- [x] Validação de formulários
- [x] Persistência com localStorage
- [x] Manipulação de dados em JSON
- [x] Organização modular do JavaScript
- [x] Depuração com DevTools

> As etapas acima representam conceitos e soluções desenvolvidos e documentados durante as experiências acadêmicas. O repositório não contém, neste momento, uma implementação integral dessas funcionalidades em código-fonte.

## Fase 3 — Implementação funcional

**Status: Planejada**

Possível evolução do projeto para uma aplicação executável:

- [ ] Estruturar arquivos HTML, CSS e JavaScript
- [ ] Implementar a interface responsiva
- [ ] Implementar navegação SPA
- [ ] Criar componentes dinâmicos
- [ ] Implementar formulários e validações
- [ ] Implementar persistência com localStorage
- [ ] Modularizar o código JavaScript
- [ ] Realizar testes de responsividade
- [ ] Realizar testes de acessibilidade
- [ ] Publicar uma versão demonstrativa

## Fase 4 — Evolução técnica

Possibilidades futuras após a implementação em Vanilla JavaScript:

- [ ] Refinar arquitetura do projeto
- [ ] Aprimorar acessibilidade
- [ ] Criar testes automatizados
- [ ] Avaliar integração com API
- [ ] Avaliar persistência de dados em back-end
- [ ] Comparar a implementação em Vanilla JavaScript com abordagens baseadas em frameworks

---

## Princípio de evolução

O Conexão Solidária será mantido como registro da evolução do aprendizado em desenvolvimento front-end.

Uma eventual implementação funcional será construída progressivamente, preservando a distinção entre os conceitos desenvolvidos durante as atividades acadêmicas e o código produzido posteriormente como evolução do projeto.
